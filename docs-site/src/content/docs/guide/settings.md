| Tab | What it holds |
|---|---|
| **General** | On this computer: the paper, the size of the interface and Wowhead links. For the app: the World of Warcraft folder, how long backups are kept, and the app's language. The app's version, and **Check for updates** |
| **Writing** | The writing model or endpoint, the narrator, margin notes, the journal's language, writing preferences, and when entries are written |
| **Characters** | Every character the app has found: **In the app**, and **On the site** |
| **Narrators** | Every narrator, and your own: [Narrators and style](/guide/narrators/) |
| **Website** | [The journal website](/guide/website/) |
| **Addon** | [The addon](/guide/addon/), installed and recording |
| **Logs** | The app's recent log, to read or copy, and its file |

![The General tab of Settings.](../../../assets/screenshots/settings-general.png)

Settings are saved as you change them, with nothing to press, except two: who writes (this
computer or an endpoint), which waits for **Save who writes** so a half-typed address never
reaches the writer, and the [website](/guide/website/), which has its own **Save**.

## Characters

Every character the app has found, with two checks. **In the app** unchecked keeps a character
out of the way, such as a bank alt: it leaves the sidebar, the home page and To review, its
journal is no longer read, and nothing is written for it. What the app already kept stays.
Checking it again reads its journal at once, which brings back the days the game still holds in
full (30 days by default, see [The addon](/guide/addon/)). **On the site** puts the character on
[the journal website](/guide/website/); it needs the character in the app.

To delete a character's history from the app instead, use **Remove from app** in the **⋯** menu
on its page.

## Updates

The app looks for a new version each time it starts and offers it in a banner. To look now, use
**Check for updates** in the sidebar, in **Settings**, **General**, or on macOS in the app menu
(**Mrglglgl**, **Check for Updates…**). The version running is shown at the foot of the sidebar,
beside **Check for updates**.

## The World of Warcraft folder

The app finds the game by itself and shows the folder it uses. Choose a folder only if it looks in
the wrong place: the game folder (the one containing `_forever_`) or a flavor folder such as
`_forever_`. **Find it automatically again** goes back to finding it by itself. A folder found
automatically is never saved, so the app still finds the game if it moves.

## Language

The app's interface is in English or French. **Language**, in **General**, is **Same as the
system** by default; choose **English** or French to override it. It is separate from **Language of
the journal** in **Writing**, which sets the language the built-in narrators write in (English or
French, or **Same as the app**).
