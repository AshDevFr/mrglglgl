# Mrglglgl app

The desktop half of Mrglglgl. It finds your World of Warcraft install, reads the journal data the
Mrglglgl addon saves for each character, keeps a full archive of it, and has the murloc scribe
write each day up as prose.

## Layout

```
Cargo.toml                pure workspace
crates/mrglglgl-core/     discovery, SavedVariables parsing, archive (no UI, no network)
crates/mrglglgl-llm/      text generation providers
crates/mrglglgl-app/      Tauri v2 shell: commands, window, bundling
ui/                       React frontend (Mantine, TanStack Query and Router, Zustand, i18next)
```

## Development

Requirements: Rust (via `rust-toolchain.toml`), Node (see `mise.toml`), and the
[Tauri prerequisites](https://v2.tauri.app/start/prerequisites/) for your OS.

```sh
make check      # build, lint and test the Rust workspace and the frontend
make dev        # run the app with hot reload
make ui-test    # frontend tests only
make build      # release build and installers
```

Builds run at low priority with two jobs by default, so a game on the same machine keeps
running smoothly. `make check JOBS=0 NICE=` builds at full speed.

Types the frontend receives from Rust commands are generated by ts-rs into `ui/src/bindings/`
when the Rust tests run; commit them with the change that produced them.

The app never writes under the World of Warcraft folder and never executes Lua.
